# ပြင်ပ source ဖြင့် တိရစ္ဆာန်အချက်များ ပြန်စစ်မှု

အဓိက source: မြန်မာနိုင်ငံ သစ်တောဦးစီးဌာန၏ [အမိန့်ကြော်ငြာစာ ၆၉၀/၂၀၂၀](https://www.myanmartradeportal.gov.mm/uploads/legals/2021/6/Notification%20690-2021.pdf)။ PDF ဖိုင်အမည်တွင် `690-2021` ဟုရှိသော်လည်း စာရွက်စာတမ်းနှင့် [အစိုးရ Trade Portal စာမျက်နှာ](https://myanmartradeportal.gov.mm/en/legal/327) တွင် `690/2020` ဟုဖော်ပြထားသည်။

`verify_external_animal_sources.py` သည် PDF ထဲတွင် သိပ္ပံအမည်ကို တိုက်ရိုက်တွေ့ပြီး ကာကွယ်မှုအပိုင်းကို အတည်ပြုထားသည့် မှတ်တမ်းများကိုသာ ချိတ်သည်။ PDF စာသား၏ စာကြောင်းနံပါတ်ကို script ထဲတွင် သိမ်းထားသည်။ ထို့အပြင် import cache ထဲက သိပ္ပံအမည်ကိုက်ညီမှု `EXACT` ဖြစ်ပြီး order/family တန်ဖိုးမပြောင်းသေးသော မှတ်တမ်းများကိုသာ GBIF taxon page ဖြင့် ချိတ်သည်။

ဤအကြိမ်တွင် ယခင် source မချိတ်ရသေးသော field **၂၂၉ ခု** ကို အတည်ပြု၍ ချိတ်နိုင်ခဲ့သည်။ **၁,၀၉၆ ခု** ကျန်ပြီး တိရစ္ဆာန် **၁၂၃ ကောင်** နှင့် သက်ဆိုင်သည် (အောက်ပါစာရင်းတွင် အသေးစိတ်ပါသည်)။

အချို့ငှက်များ၏ မူလ `protection_basis_my` က မျိုးရင်းအလိုက်ဟု ရေးထားသော်လည်း PDF တွင် မျိုးစိတ်အမည်ကို တိုက်ရိုက်ရေးထားသဖြင့် basis ကို ပြင်ထားသည်။ ထိုအချက်များအတွက် PDF ကို field source အဖြစ် သိမ်းထားသည်။ `data/protected_birds_2020.json` နှင့် `data/totally_protected_mammals_2020.json` တို့တွင် မူလ catalog မှတ်တမ်းများ ကျန်ရှိသေးသဖြင့် importer ကို ပြန်မောင်းမီ ဤ audit script ကို ပြန်မောင်း၍ တရားဝင်စာရင်းနှင့် ညှိရန်လိုသည်။

## ဆက်စစ်ရန်

[Source မချိတ်ရသေးသော animal field စာရင်း](unverified_animal_field_sources.md) တွင် ကျန်သည့်မှတ်တမ်းများကို တိရစ္ဆာန်အမည်နှင့် field အလိုက် ဖော်ပြထားသည်။ စာသားရှည် field တစ်ခုအတွက် species page တစ်ခုရှိရုံဖြင့် အဆိုပါစာသားတစ်ပိုဒ်လုံးကို အတည်ပြုပြီးဟု မယူဆထားပါ။ မူရင်းစာသား၏ claim အားလုံးကို source က ထောက်ခံမှသာ ချိတ်ရန် ကျန်ရှိသည်။
