# တိရစ္ဆာန်အလိုက် source ချိတ်ရန်ကျန်သော field များ — 02/03/04

လက်ရှိ `wildlife.db` ကို အခြေခံထားသည်။ Data ဖြည့်ထားပြီး `field_sources` တွင် ထို field အတွက် URL မရှိသေးသည့်အချက်များကိုသာ ဖော်ပြသည်။ Source မချိတ်ရသေးခြင်းသည် data မှားကြောင်း အတည်ပြုခြင်း မဟုတ်ပါ။

- စာရင်းဝင်တိရစ္ဆာန်: **123 ကောင်**
- Source ချိတ်ရန်ကျန်သော field: **875 ခု**
- 02. ဖော်ပြချက်နှင့် နေထိုင်မှု: **363 ခု**
- 03. ထိန်းသိမ်းရေးနှင့် မျိုးခွဲ: **424 ခု**
- 04. ဥပဒေအရ ကာကွယ်ထားမှု: **88 ခု**

အချက်အလက်မဖြည့်ရသေးသော field များကို မရေတွက်ပါ။ 04 အောက်ရှိ `taxon_rank` သည် မှတ်တမ်းအဆင့် metadata၊ `image_credit` သည် ဓာတ်ပုံခရက်ဒစ်ဖြစ်သောကြောင့် field source ချိတ်ရန်စာရင်းတွင် မပါဝင်ပါ။
