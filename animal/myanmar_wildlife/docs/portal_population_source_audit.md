# အကောင်ရေဆိုင်ရာ field များ၏ source တိုက်စစ်ချက်

စစ်ဆေးသည့်နေ့: ၂၀၂၆-၀၉-၁၈။ ဤစစ်ဆေးချက်သည် project တွင် သိမ်းထားသော Myanmar Biodiversity Portal မူရင်းစာသားကို field တစ်ခုချင်းစီနှင့် နှိုင်းယှဉ်ထားခြင်းဖြစ်သည်။ မျိုးစိတ်၏ scientific name နှင့် portal link ကိုလည်း တိုက်စစ်ထားသည်။ Source ကိုယ်တိုင်၏ သိပ္ပံဆိုင်ရာ နောက်ဆုံးရဖြစ်မှုကို ဤအဆင့်တွင် မအတည်ပြုထားပါ။

## ရလဒ်

- Source link မရှိသော field ၅ ခုကို user ညွှန်ကြားချက်အရ ဖယ်ရှားထားသည်။ မူလတန်ဖိုးကို `removed_unsourced_population_fields.json` တွင် သိမ်းထားသည်။
- အရင်က မစစ်ရသေးသော source ချိတ်ထားသည့် field ၈၉ ခုအနက် ၇၄ ခုသည် သိမ်းထားသော source စာသားနှင့် ကိုက်ညီသည်။ ၁၅ ခုတွင် ဘာသာပြန်၊ ကိန်းဂဏန်းအကန့်အသတ် သို့မဟုတ် နယ်မြေအဓိပ္ပာယ်လွဲမှုကို ပြင်ထားသည်။ တစ်ခုချင်းစီကို `portal_population_source_audit.csv` တွင် ဖော်ပြထားသည်။
- ယခု data ရှိသည့် field ၁၁၅ ခုစလုံးတွင် field အလိုက် source link ရှိသည်။ ထိုအထဲမှ ၄၁ ခုသည် source နှင့် ပြန်တိုက်ပြင်ထားပြီး ၇၄ ခုသည် source စာသားနှင့် တိုက်စစ်ရာတွင် ကိုက်ညီသည်။
