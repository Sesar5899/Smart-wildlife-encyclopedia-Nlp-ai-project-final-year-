# အကောင်ရေ field များ၏ source နှင့် ရက်စွဲ စိစစ်ချက်

မူရင်းစာမျက်နှာမှ ၂၀၂၆ ခုနှစ်တွင် ကူးယူထားခြင်းသည် ကိန်းဂဏန်းကို ၂၀၂၆ ခုနှစ်တွင် စစ်တမ်းကောက်ယူခဲ့ကြောင်း မဆိုလိုပါ။

- ဖြည့်ထားသော field: **115 ခု**
- Source နှင့် အဓိပ္ပာယ် ပြန်တိုက်ပြီး ပြင်ထားသော field: **41 ခု** (အားလုံး နောက်ဆုံးရစာရင်းဟု မဆိုလိုပါ)
- သိမ်းထားသည့် source စာသားနှင့် တိုက်စစ်၍ ကိုက်ညီသော field: **74 ခု** (နောက်ဆုံးရဖြစ်ကြောင်း မအတည်ပြုရသေးပါ)
- Source ရှိသော်လည်း နောက်ဆုံးရဖြစ်ကြောင်း အတည်မပြုနိုင်သေးသော field: **0 ခု**
- Field အလိုက် source နှင့် နောက်ဆုံးရအခြေအနေ မအတည်ပြုရသေးသော field: **0 ခု**

အသေးစိတ်စာရင်းကို population_currentness_review.csv တွင် ကြည့်ပါ။ `source_linked_recency_unverified` ဆိုသည်မှာ မှားသည်ဟု ဆုံးဖြတ်ထားခြင်း မဟုတ်ပါ။
